# bread-ui-kit

Local forks of components that normally live in `@breadcoop/ui`, kept here
because Stacks is currently the only app consuming their updated design —
Solidarity Fund and Safety Net haven't picked it up yet.

Each component in this folder should be moved back into the shared
`@breadcoop/ui` library once it's actually used across all three apps
(Solidarity Fund, Stacks, and Safety Net). Until then, iterate on it here
rather than in the library, so changes don't leak into apps that aren't
ready for them.
